# Windows 客户端候选版

解压 `ContinuityBridge-Windows` 文件夹，双击 `ContinuityBridge.App.exe`。这是当前用户会话的托盘程序；不安装 Windows Service。通知区域可能需要展开隐藏图标。

首次设置填写 Relay 的 HTTPS origin 和此 Windows 设备专用的 64 位十六进制 token。地址只含协议、主机和可选端口，不带 `/v1`、查询或用户名。设备 token 写入 Windows 凭据管理器；普通设置文件不含 token。令牌须由 Relay 管理者在本机安全交接，不要发到聊天或截图中。

默认不启用同步。阅读设置中的说明后勾选自动同步并保存。此后本地新复制的纯文本/图片自动发送；远端未过期项自动写入剪贴板。启动前已有的内容不自动上传，但远端内容可能覆盖当前本地内容。普通文件列表不发送。

v1 使用 HTTPS，服务器仍可读取正文，不是端到端加密。默认云端只存最新一项 30 分钟，服务重启清空；到期和“清空云端”都不会清空本地。显式私密格式会被过滤，但无法识别所有密码，复制敏感内容前请暂停同步。

托盘菜单提供设置、暂停/恢复、清空云端及退出。暂停会取消网络和待发送正文，恢复不补传暂停前旧内容。离线复制仅在内存暂存最多 120 秒；恢复后云端已变或候选过旧时不抢占，请重新复制。发生竞争时可能需要重新复制或再次清空。网络状态为 HTTP 轮询时，仍可同步；默认每 5 秒读取元数据。

登录启动是可选项，只修改当前用户的 `Run/ContinuityBridge` 项。先将解压文件夹放在稳定位置，再启用；搬动文件夹后重新保存登录启动设置。取消此选项即可移除本程序的登录启动项。

此候选要求具有 `/v1/identity` 的 SHA-B Relay。连接旧 P2 服务时会提示服务不兼容，须先由 P3 更新 staging。配置错误、凭据撤销或网络不可用时不会上传启动前剪贴板。

图片支持注册 PNG、JFIF/JPEG、DIBV5、DIB，以及 Windows 从 bitmap 提供的 DIB。PNG/JPEG 尽量保留原编码；只有 bitmap 时编码 PNG。下载写入 PNG、保留透明度的 DIBV5、白底合成的旧 DIB。单图本机上限为 16,000,000 像素及估算 320,000,000 字节工作内存，并服从服务器更低限额；不会通过缩图或降低质量绕过限制。未验证的私有 HEIC 剪贴板格式、动画、多图、普通文件不作支持承诺。

当前分发包没有代码签名证书，应用 EXE 未签名。不要关闭 Defender、SmartScreen 或其他安全防护。若系统阻止运行，保留拦截并由使用者按本机政策审查候选来源；本项目不自动绕过。

退出后可以移除本候选文件夹；保留或删除当前用户设置由用户决定。回退至上一已保留的客户端候选前，先暂停并退出。Relay 回滚由 P3/P7 的独立计划执行。

本包是 P5 候选，不表示 P6 iPhone↔Windows E2E 或 P8 日常脱离开发环境验收已完成。
