# 05 测试、跨机自动化和验收

## 1. 四个证据层次

L0 单元测试：大小、TTL、幂等、状态竞争、序号、去重、错误路径。

L1 接口/进程测试：真实 Relay HTTP/WSS、Linux 部署、二进制完整性、重启、撤销 token、代理响应。

L2 真实设备测试：Windows 当前用户桌面真实 Clipboard；Mac 通过现有 Mobile MCP/WDA 操作 USB iPhone；执行真实快捷指令并粘贴。

L3 日常脱离开发工具：Mac 关机/USB 拔掉、产品两端公网工作，网络变化后可恢复。

不同层不能互相替代。Mac `shortcuts run` 不是 iPhone 测试；SSH/WSL/无人登录的 CI 不能直接证明用户桌面的剪贴板行为。Windows 服务与用户会话隔离见 [S13]。Mobile MCP 安装/设备能列出不等于已完成 L2。[S6][S7]

## 2. 自动化协调：产品以外的受限测试设施

三个 Codex 会话不会因为共用 GitHub 自动指挥彼此。基线做法为：用户在 Windows 当前桌面启动一次测试 runner；Mac Codex 执行唯一的 E2E 场景控制会话。

为不依赖 LAN/Tailscale，P5 实现最小 **staging-only QA mailbox/sidecar**。Windows runner 主动通过 HTTPS 领取合成测试动作；Mac 控制端通过同一测试入口提交 fixture ID、等待状态。产品 Relay 的最新剪贴板正文与 QA 状态严格分离。此测试设施必须独立组件、独立密钥，生产镜像/部署不包含或不路由该设施，不能成为产品运行依赖。

命令白名单仅允许 `SetFixtureClipboard(fixtureId)`、`VerifyClipboard(fixtureId)`、`Status`、`EndRun` 等固定操作。fixtureId 必须来自已提交的合成 fixture 清单，不能是任意文本、文件路径、URL、命令或脚本。禁止 shell/PowerShell 执行、任意文件读取、任意剪贴板外传能力。

每个 run 绑定 candidate SHA、短期随机 runId、controller/runner 两类凭据、租约和超时；Windows agent 手动启用，托盘/窗口明确显示测试状态、可立即停止。一个真机/剪贴板只能有一个活动 run。测试报告与少量状态限额保存，不允许无限任务队列；无真实用户数据，默认短期清理。

这是用户批准运行 P6 后才启用的测试控制器，不是新建无鉴权远程控制后门。若现有安全的工具控制已经能满足跨机编排，可在 ADR 中用等价更小机制替代，但不得重新引入 LAN/Tailscale 产品前提或暴露 WDA/MCP。若此协调器未实现，只能交付“分端辅助测试”，不能声称一键全自动 E2E 已实现。

## 3. iPhone 测试 oracle

Appium 官方说明真实 iPhone 的 WDA 剪贴板 get/set 可能要求 WDA 位于前台；不能把空值当真实为空，也不能假定 Mobile MCP 暴露所有图片剪贴板能力。[S11]

采用三层证据：

- 产品实际快捷指令 Send/Retrieve 跑通，后端长度/hash 匹配 fixture。
- 在预先建立的“CB 测试”便笺/安全测试 App 中实际粘贴；图片必须是图片对象，不是路径、链接、字典或文件占位。
- 必要时增加**测试专用**快捷指令 `CB 测试校验`：从当前手机剪贴板读取 fixture，回传到独立 QA oracle 做类型/长度/图像解码比较。仅在活动测试租约和匹配的合成 fixture 场景中使用，不在生产运行、不上传个人剪贴板。

运输阶段尽量要求字节 SHA-256 相同；系统/应用重新编码时比较解码后的像素、宽高、透明通道和方向，并记录为何字节不同。截图只能证明视觉外观，不能独自证明完整长文本或无损图片传输。

## 4. 主要矩阵

| ID | 场景 | 关键预期 | 层 |
|---|---|---|---|
| T01 | 两方向短文本 | 原生复制/粘贴完整，无路径或 JSON | L2 |
| T02 | 长中文、emoji、多行、首尾空白 | 无 `...` 截断，不丢换行/字符 | L0/L2 |
| T03 | 不支持/NUL/超长文本 | 明确失败，不替换有效项 | L0/L1 |
| I01 | Windows 截图 → iPhone | 手机可实际粘贴图片 | L2 |
| I02 | iPhone 复制图片 → Windows | Win32 真实图片格式，目标可粘贴 | L2 |
| I03 | 透明 PNG | 尺寸/alpha/方向保持 | L1/L2 |
| I04 | JPEG 与 bitmap-only 源 | 无意外有损二次转换；记录编码策略 | L2 |
| I05 | 正好 20,000,000 字节合法图片 | 成功，不按 MiB 错算 | L1；接近边界需 L2 |
| I06 | 20,000,001 字节、chunked 超限 | 413，旧项保留，内存有界 | L0/L1 |
| I07 | 畸形图、尺寸炸弹、APNG/GIF | 受限拒绝，不挂住 UI/服务器 | L0/L1 |
| I08 | 复制 .png 文件而非图片数据 | 忽略普通文件，不能偷换范围 | L2 |
| S01 | 图片后复制文本 | 全局一个最新项，不分类型保留 | L0/L2 |
| S02 | 同一 requestId 重试 | 不重复提交/续期，无正文历史缓存 | L0/L1 |
| S03 | 同键不同正文 | 409，不误返回成功 | L0/L1 |
| S04 | 两端竞争/旧上传晚到 | CAS 明确冲突；旧任务不覆盖新动作 | L0/L2 |
| S05 | 下载中本地新复制 | 旧远端结果不能覆盖本地 | L0/L2 |
| S06 | 通知丢失/重复/重连 | GET 收敛，无回环上传风暴 | L0/L1/L2 |
| S07 | WSS 不通、HTTPS 正常 | HTTP 元数据降级，不反复下大图 | L1/L2 |
| S08 | 重启/离线重连 | 新 epoch，旧项不复活，不上传启动前内容 | L0/L2 |
| E01 | TTL 假时钟边界 | t<expiry 可读，t>=expiry 不可读 | L0 |
| E02 | staging 真正等待 30 分钟 | 到期无法新取回，设备已获内容不自动清除 | L1/L2 |
| E03 | 设置短 TTL/调图片限额 | capabilities 与实际强制一致 | L0/L1 |
| A01 | 缺 token、撤销、伪造设备 ID | 无未授权读写，撤销即时生效 | L1 |
| A02 | 日志/错误/导出检查 | 无正文、token、截图秘密进入 Git/日志 | L1 |
| W01 | 托盘暂停/恢复/退出 | 暂停不传、恢复有定义、退出释放资源 | L2 |
| W02 | 用户登录启动/重复启动 | 用户会话运行、单实例、可关闭自启 | L2 |
| W03 | 私密格式/自写标记/序列号回绕 | 不泄漏显式私密内容、不回环、不永久卡死 | L0/L2 |
| D01 | Mac 关机、USB 断开 | 产品仍双向工作 | L3 |
| D02 | 手机蜂窝、电脑独立网络 | 不依赖同 LAN；HTTPS 可达时工作 | L3 |
| D03 | 服务更新/回滚 | 精确镜像可识别，恢复旧版可操作 | L1 |

20 MB fixture 必须是合法图像，可以用标准允许的 ancillary chunk 或可解释编码生成边界数据，不能简单尾部随便补字节后声称代表正常图片。所有素材程序生成，无个人内容。

## 5. 性能记录而非虚构 SLA

记录小文本与小图片从“发送动作开始”到“目标可粘贴”的 p50/p95；记录 20 MB 的耗时、两端编码/网络/服务端分段耗时。建议 v1 对可用网络下小文本以数秒内为体验目标，但纽约或其他跨境 VPS 的往返时延/线路未测前不能保证 1 秒。不能以 4 核 8 GB 规格直接推断跨网体验。

## 6. 测试安全与报告

先提醒用户测试将覆盖剪贴板；仅对支持格式做本机内存备份/尽力恢复，不承诺还原任意私有/OLE 延迟格式。不能把备份正文传给 QA、Codex 或 Git。测试期间出现非 fixture 的剪贴板内容就暂停该用例，报告不含其原文。不要自动关闭用户浏览器/插件/密码管理器，不去私人聊天 App 寻找素材。

TestAgent 安全 gate：未启用时零剪贴板读写/零 QA 连接；启用后先核验真实 QA 响应的服务身份、runner 角色、runId、session、完整候选 SHA、活动状态和租约，再建立完整、有界、独立的本机内存快照，最后写 sentinel。未知混合格式、快照失败/超限/竞争默认不覆盖。不能通过不备份或丢弃不支持格式来获得 READY。

所有退出原因统一取消并等待命令、原生工作及隔离的测试同步；恢复也在临界区核对本次所有权和序号。用户的新复制必须保留，即使内容等于 fixture。排空/恢复有时限；无法证明排空时不恢复、不重新启用，不承诺进程强杀/断电恢复。恢复正文不进入 QA 或自动上传，产品读取正文前执行本条禁止上传标记。启动/结束时的互斥、staging 内存配置与格式/资源边界见 [QA runbook](windows/QA_RUNBOOK.md)。

这条 gate 的 mock/本机 HTTPS 回归不能替代真实桌面：需要人工确认测试窗口并保管当前内容后，另行验证真实文本/图片快照、用户新复制、停止/关闭/租约到期和恢复不上传。此次 P5 安全修复的 L2 标记 NOT RUN，不输出 P6-W READY。

每条结果记录 runId、source SHA、测试文件 SHA/fixture 清单、dirty 状态、执行主机角色、工具版本、用例、预期/实际、PASS/FAIL/BLOCKED/NOT RUN。原始截图/UI tree/日志留在本机被忽略 artifacts/，共享版本只含脱敏摘要。

阶段统计要包括 NOT RUN/BLOCKED；不得把被跳过测试算通过。只有同一候选版本、真实两端证据齐全，才可称为“双向图片 E2E PASS”。
