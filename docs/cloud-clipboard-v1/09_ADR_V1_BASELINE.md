# ADR-001：云端剪贴板 v1 基线

日期：2026-09-10。状态：P0 设计决策，供后续明确授权阶段实现；不代表软件或真机 PASS。证据基线及复核方式见 [P0 报告](10_P0_BASELINE.md)。

## 九条需求与验收映射

| ID | 已确定的需求 | 决策及主验收 |
|---|---|---|
| R1 | 只同步文本、图片，不同步普通文件 | Unicode 纯文本和真实图片对象；CF_HDROP 文件列表忽略。T01–T03、I08 |
| R2 | 图片双向 | Windows→iPhone 和 iPhone→Windows 均要实际粘贴图片。I01–I04 |
| R3 | iPhone 手动 | CB 发送、CB 取回；不承诺 iOS 后台监听。P4、P6-M |
| R4 | Windows 自动 | 登录用户会话托盘监听、上传、接收与落地；显式启用自动同步。W01–W03 |
| R5 | 不依赖 LAN/Tailscale | 公网可信 HTTPS/WSS；Mac/USB 不在产品运行路径。D01、D02 |
| R6 | v1 使用现有 4 核 8GB VPS，保留 Cloudflare 替换空间 | 独立可移植 .NET Relay；该规格为用户输入，P3 再测资源。契约和黑盒测试复用，后端运行时可重写 |
| R7 | 云端仅全局最新一项、保留 30 分钟 | 一个设备组一个槽位，文本/图片相互替换；成功原子提交开始计时。S01、E01、E02 |
| R8 | 图片 20MB，TTL/大小可配置 | 20,000,000 最终编码字节；capabilities 与实际强制值一致。I05–I07、E03 |
| R9 | v1 明文经 TLS，v2 预留真正 E2EE | v1 只接受 none，服务器能读正文；未来独立版本 envelope，设备持钥且拒绝降级。A01/A02、C10 |

## 采用的补充默认值

这些是本阶段设计选择，不冒称用户逐项指定。生产前必须再次明示重启清空临时项和快捷指令凭据存储边界。

| 项目 | v1 默认与约束 |
|---|---|
| 图片 | 静态 PNG/JPEG；客户端将可解码的其他静态格式转 PNG；拒绝 APNG/GIF/动画，不能静默缩尺寸、损失 alpha 或有损压缩以过限 |
| 文本 | decoded UTF-8 最多 1,000,000 字节；原样保留空文本、换行、空白、emoji；拒绝 NUL、非法 UTF-8、未配对代理项；JSON 封装默认最多 8,000,000 字节 |
| 像素 | 最多 64,000,000 解码像素；校验编码、尺寸及有限解码资源，不能只查文件长度 |
| 生命周期 | retentionSeconds=1800；expiresAt=服务端原子提交时刻+该次生效 TTL；到期边界为 now>=expiresAt；GET/重放不续期；配置变更只影响新项 |
| 存储 | 单实例内存槽位、有限在途缓冲；重启正文及幂等记录清空，生成新 serverEpoch；不承诺物理取证级擦除，P3 检查 swap/dump/代理落盘 |
| 幂等 | 按认证设备+UUID 键索引；只留请求指纹/结果元数据/时间；默认最多 512 条/实例，TTL=min(1800, retentionSeconds) 秒，按最初提交计时且重放不刷新 |
| 离线候选 | 只保留本机内存中最新候选，默认最大年龄 120 秒（单调本地计时，可配置）；须有捕获时的已知云 ETag；断线恢复先 GET。ETag/epoch 未变、年龄合格、generation 未变才尝试原条件提交；冲突、过期、无基线则丢弃自动补传并提示，不清本地 |
| 前台竞争 | 当前在线的新鲜复制收到 412 后，GET 并确认仍是最新本地动作，至多用新键重试一次；旧离线候选不抢占。网络结果未知时只重试原键、原条件和原正文 |
| 重连应用 | 本地待处理/被丢弃的离线动作保护当前本地；不应用恢复时那条旧云快照，将它作为已观察基线；此后新的远端提交按正常核验接收。启动前剪贴板不上传；启动后新复制优先 |
| 降级 | WSS 只提示变化，REST 为当前状态权威；HTTP 降级默认每 5 秒查询元数据，失败指数退避至 60 秒并加抖动；暂停后停止网络与待提交任务 |

没有把 512 条元数据等同于 512 条正文历史。替换/到期/取消后释放正文引用；受限下载快照应在替换/到期时取消并有超时，已传出的字节无法召回。清空云端和自然过期都不清设备剪贴板。

## 契约决策与可移植边界

[OpenAPI](contracts/openapi.json) 定义 HTTP 方法、鉴权、输入输出与状态码；[JSON Schema](contracts/schemas.json) 定义 JSON/头部值及 WSS 提示。动态字节限额、原子性、时序和图片合法性由 [验收清单](11_ACCEPTANCE_AND_HANDOFF.md) 的真实服务测试验证，不能用 Schema 通过替代。

- `revision` 是无前导零的十进制字符串；每次启动从 `"0"` 开始，服务端逻辑上无回绕。ETag 是带双引号的单个强状态 token，由 epoch/revision 唯一确定或等价保证不复用；客户端不可解析。GET 空状态也有 ETag。拒绝通配符、多 ETag、弱 ETag。
- 到期在任意状态访问/CAS 前原子结算且只递增一次；后台清理不能再次递增。DELETE 即使槽位已空也递增，使被淘汰的旧清空请求无法再次通过旧条件。epoch 变化使所有旧条件失效。
- 统一成功响应为 200；写入/清空返回 `MutationReceipt`。`result` 是原始提交的状态元数据，`state` 是响应快照时的当前状态，`available` 只说明原 put 项此刻仍当前且未过期（clear 总是 false）；不保证客户端收到时仍有效。重放只更新当前状态快照，不写入、不续期，客户端不得盲用旧 result 写剪贴板。
- 请求指纹绑定方法、路径、规范化媒体类型、cryptoMode、原 If-Match 与完整逻辑正文（文本解码后严格 UTF-8，图片原始字节，clear 为零字节）。使用有长度边界的编码后 SHA-256；JSON 属性顺序和转义写法不影响相同文本。相同键改变其中任一值返回 409。未成功的操作不占已完成结果缓存；同键并发必须原子合并或串行判定，不能双提交。
- 请求须先鉴权、校验头部、受限读取并验证，再在同一原子区处理到期、查幂等、CAS 与提交。认证在重放查询前执行，撤销凭据不能取回历史结果。缓存淘汰或重启后旧键失去重放资格，但原条件会因状态不复用而失败。
- 文本 JSON 可带 `cryptoMode`，缺省 none；图片通过可选 `X-CB-Crypto-Mode` 传递，缺省 none；任何未知模式返回 415。v1 不接收 keyId/nonce/密文 envelope；未来在独立协议版本定义 AEAD 算法、nonce、keyId、AAD、密钥管理和加密内层 mime/hash。没有加密时不宣称 E2EE。
- v1 不提供历史列表、任意文件路径、下载链接、Range/断点续传或上传 URL；忽略合法 Range 头并返回完整 200 正文，不返回 206。无效/未知 itemId 按 400/410 处理，不泄漏历史存在性。

## 替代范围与后果

本 ADR 替代旧计划的约 2GB 普通文件、LocalSend 产品集成、Range 和 Tailscale Receiver 路径。原始本地计划/报告保持原样并继续忽略；不删除工具、不改网络、不宣称旧 G2 已完成。新 P0 授权独立于旧 Phase D 阻塞；被复用的 Win32 功能在 P5/P6 仍需真实回归。

P2 才新增 Contracts/Relay `net10.0` 和真实可移植测试，不将旧 Windows Core 整体搬到云端。P4 必须先验证 iPhone ETag 请求头、二进制图片上传/取回/原生粘贴及错误处理；P5 在这些关键能力明确后展开。具体所有权与审批见 [阶段门槛](11_ACCEPTANCE_AND_HANDOFF.md)。
