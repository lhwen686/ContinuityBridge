# iPhone 快捷指令模板

这两份文件来自 macOS Shortcuts **文件 → 导出 → 任何人**，是 Apple 签名的
AEA1 文件，不是改名的 JSON/plist。真机结果和限制见
[P4 实测报告](../lab/p4-real-iphone-results.md)。

- [CB 发送.shortcut](CB%20发送.shortcut)：读取一次真实手机剪贴板，发送文本或图片。
- [CB 取回.shortcut](CB%20取回.shortcut)：下载、校验并在复制前重查状态，再拷贝正文或图片。

## 本机配置

1. 在 iPhone 新建不分享的 **CB 配置**，添加 **字典** 动作。
2. 添加文本键 `BaseURL`、文本键 `DeviceToken`、数字键 `ProtocolVersion`。
   用户在本机填入 staging HTTPS origin、token 本身、数字 `1`。
   BaseURL 不带末尾 `/`；token 不带 `Bearer ` 或字段名前缀；键名不能有尾随空格。
3. 导入两个模板。分别打开编辑器，点 **运行快捷指令** 动作中的名称，重新选择
   本机的 **CB 配置**。发送的配置动作位于最初的剪贴板读取/类型判断之后。
   这一步消除导出机器上配置快捷指令内部标识的绑定差异。
4. 退出配置编辑页。运行产品快捷指令时，按需要允许运行配置、连接 staging 和拷贝。
   **不要单独运行、截图、导出或分享已经填入秘密的 CB 配置。**
5. 在目标 App 复制合成文本或图片，再运行 **CB 发送**；运行 **CB 取回** 后，
   回到指定测试 App/便笺使用系统 **粘贴**。

未发现本实验室可用的独立 Keychain 辅助能力。纯快捷指令里的 token 能被有权编辑
该快捷指令的人查看，也可能随快捷指令同步或分享；不能把它当作独立 Keychain 保险库。
本目录不提供含秘密的配置文件，不包含生产 token。

## 已验证范围

真实 iPhone18,2 / iOS 26.6.2，系统语言为简体中文。类型比较使用本次系统实际输出的
`文本` / `图像`；其他语言须重新验证，未承诺跨语言直接运行。已验证长文本、PNG、JPEG；近 20 MB 单轮实测
与错误行为见报告。PNG/JPEG 图片对象优先保留原始编码；其他真实图片对象才尝试
**转换图像 → PNG**，其他类型不在已通过的支持承诺中。

发送只读一次真实剪贴板，不使用文件选择器或上传文件入口寻找替代源。
取回最后的拷贝动作分别绑定 `ClipboardText` / `ClipboardImage`；完成提示不会写入剪贴板。
HTTP 错误可能继续成为字典，模板检查错误码及完整性，不能只看 HTTP 动作是否结束。
